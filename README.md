# CHAI CATCHER: DESI DASH

An anime-style Indian street-food catching game by Prince Patel.

## 🎮 Game Overview

Catch delicious Indian snacks while avoiding rubbish items in this fast-paced arcade game. Build combos, activate power-ups, and compete for the highest score!

### Features
- **3 Game Modes**: Classic, Endless, and Challenge modes
- **Combo System**: Chain catches for score multipliers
- **Power-ups**: Shield, Magnet, Slow Motion, and Double Score
- **Persistent History**: Track your best scores and game statistics
- **PWA Support**: Install as a mobile app
- **Responsive Design**: Play on mobile, tablet, or desktop
- **Original Art Style**: Anime-inspired Indian street food theme
